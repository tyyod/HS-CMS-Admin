HS-CMS API接口文档

文章模型说明

文章模型（Article）包含以下字段：

  • id (bigint unsigned): 文章ID，主键，自增
  • title (varchar(255)): 标题，必填
  • brief (varchar(512)): 摘要
  • content (longtext): 正文内容，必填
  • content_format (varchar(16)): 内容格式，默认'html'，可选值：md/html
  • post_type (tinyint): 文章类型，默认0，0-原创，1-转载
  • status (tinyint): 状态，默认1，0-草稿，1-正常，2-审核中，3-审核失败，4-限制访问，5-禁止访问
  • cover_url (varchar(500)): 封面图URL
  • author_id (bigint unsigned): 作者ID，必填
  • category_id (int unsigned): 分类ID，必填
  • original_author_name (varchar(100)): 转载文章的原始作者名字
  • original_url (varchar(500)): 转载文章的原始文章链接
  • published_at (datetime): 文章正式发布时间，草稿状态下为NULL
  • is_deleted (tinyint): 是否删除，默认0，0-未删除，1-已删除
  • created_at (datetime): 创建时间
  • updated_at (datetime): 更新时间

1. 获取文章列表（后台）

GET /api/admin/articles/list
需要登录 请求参数：
  • page (int, 可选)：页码，默认1
  • page_size (int, 可选)：每页数量，默认10
  • category_id (int, 可选)：分类ID
  • tag_id (int, 可选)：标签ID
  • order (string, 可选)：排序方式（latest/recommend/hot）
  • keyword (string, 可选)：关键词搜索
返回示例： 
{
  "code": 0,
  "msg": "success",
  "data": {
    "list": [
      {
        "id": "b71def84313d",
        "title": "文章标题",
        "abstract": "摘要内容",
        "cover_url": "https://xxx.jpg",
        "author": { "id": 1, "name": "张三", "avatar": "https://xxx.png" },
        "category": { "id": 1, "name": "前端" },
        "tags": [{ "id": 1, "name": "Vue" }],
        "post_type": 0,
        "status": 1,
        "view_count": 100,

        "published_at": "2024-06-01 12:00:00",
